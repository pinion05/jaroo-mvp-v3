## 10. 권고 (사용자 관점, 우선순위순)

1. **열람과 재실행 분리** (§5-A/B): 기록 항목·/deepscan 방문이 조건 없이 유료 재실행으로 이어지지 않게, "최신 결과 다시 보기(무료)"와 "새로 분석(10cr)"을 명시적 분리. 특히 /deepscan 재방문의 자동 재실행·과금은 사용자 동의 없는 과금 표면.
2. **임의 종목 1회 분석 진입로** (§4): 보유 추가 없이 종목 검색으로 1회 딥스캔하는 경로(또는 /deepscan 검색 UI) 필요. 현재는 포트폴리오 추가가 강제.
3. **ETF 위원 서술과 지표 패널 수치 동기화** (§5-F): 같은 화면에서 두 개의 다른 "1개월 수익률"이 노출됨.
4. **ETN 분석의 기록 등록·과금 규칙 정합** (§5-D/E): 무과금+미등록 조합은 사용자 장부(마이 수치)와 기록이 어긋나게 만듦. ETN 구성은 "이 상품은 구성 종목이 없는 인버스 ETN이에요" 류 안내로 교체.
5. 기록 시장 라벨 통일(KR/KOSPI 혼용, §5-G).
6. 위원 개별 완료 카운트(9명 중 n명) 표시가 없어 진행 체감이 팀 3단계에만 의존 — 대기 구간(26–41초 API 홀드)에서 "몇 명 남았는지" 표시 권장.
