# TC-Blackbox-Data — 금융 데이터 표시 신뢰성 (블랙박스)

- 문서 ID: TC-blackbox-data
- 대상: jaroo 금융 데이터 표시 신뢰성 (시세·평가액·손익률·목표가·날짜의 사용자 관점 신뢰성)
- 작성: 2026-11-06 (KST) / 담당: 블랙박스 TC
- 스크립트: `scripts/blackbox-data-sanity.cjs` (TC-BBD-001 ~ TC-BBD-028)
- 최종 실행 판정 분포: **PASS 8 / FAIL 1 / WARN 4 / SKIP 15 — 총 28 TC** (exit 1, FAIL 존재)

## 1. 블랙박스 원칙과 기대값 출처

제품 소스(src/, packages/, tests/, scripts/ 기존 파일, docs/)는 일절 열람하지 않았다.
모든 기대값은 아래 4가지 출처에서만 도출했으며 각 TC에 출처를 명시한다.

1. **공개 금융 관행**: 한국 상승=빨강/하락=파랑, 원화 천단위 콤마, % 표기, 시세 기준 시각 표시 관행
2. **상식적 값 범위(공개 사실)**: 예) 삼성전자 주가 5만~30만원 수준, KODEX 코스피(KOSPI 추종 ETF) 1만~10만원 수준, 국내 상장 유가증권 100원~1,000만원 상식 한도, 일중 등락률 ±30% 초과 표시는 오류 신호
3. **산술 일관성**: 화면 내 값들 간 정합 (Σ종목 손익=총 손익, 손익률=손익/매입액, 평가금액=수량×현재가)
4. **크로스환경 일관성**: dev(jaroo-dev.up.railway.app) ↔ local(127.0.0.1:3002) 동일 화면 비교

## 5. 수기 실측 보강 — 이전 세션(박명철, 보유 6종목) 증거

세션 소실 전(2026-11-06 00:33~00:35 KST) 홈 화면에서 수집한 값. 전형적인 블랙박스 산술 검증이다.

**요약**: 총 평가액 `8,425,745원` · 총 손익 `−2,500,157원 · −22.9%` (손실)

| 종목 | 시장/코드 | 수량 | 손익률 | 손익(원) |
|---|---|---|---|---|
| KODEX 코스피 | ETF·226490 | 111주 | -16.4% | -1,210,344 |
| SNT에너지 | KOSPI·100840 | 51주 | -37.4% | -736,134 |
| 삼영화학공업 | KOSPI·003720 | 177주 | -31.7% | -397,719 |
| SOOP | KOSDAQ·067160 | 3주 | -44.2% | -88,257 |
| 파미셀 | KOSPI·005690 | 7주 | -49.9% | -60,739 |
| 삼성 인버스 코스피 200 선물 ETN | ETN·530092 | 1주 | -68.5% | -6,964 |

검증 결과 (모두 **일치**):

1. Σ종목 손익 = −2,500,157원 = 총 손익 **정확 일치** (차 0원)
2. 총 손익률: 매입액 = 8,425,745 − (−2,500,157) = 10,925,902원 → −2,500,157/10,925,902 = **−22.88% ≈ −22.9%** 일치
3. KODEX 확장행: 현재가 55,490원 · 평단 66,394원 · 평가금액 6,159,390원 → 111주×55,490 = **6,159,390원 정확 일치**; 손익 6,159,390 − 111×66,394(=7,369,734) = **−1,210,344원 일치**; 손익률 −1,210,344/7,369,734 = **−16.42% ≈ −16.4% 일치**
4. KODEX 코스피 현재가 55,490원 — KOSPI 추종 ETF 상식 범위(1만~10만원) 내
5. 라벨 정합: 6종목 모두 "손실" 라벨 + 음수 부호/청색 계열 표시로 일관 ("6개 중 6개가 손실 구간이에요" 문구와도 정합)
6. 콤마 포맷: 노출 금액 전부 천단위 콤마 정상

**이 세션에서 관찰한 표기 이슈**: 요약 영역은 U+2212(−), 종목 행은 ASCII(-)로 부호 글리프 혼용. "삼영화학공업**는**" 조사 오류(은/는). 하단 시트 문구 "KODEX 코스피는 -16.4% 상태예요"처럼 행 손익률 재사용은 정합.

## 7. 특이사항·사고 보고

1. **이전 세션(박명철 실계정) 소실**: 탐색 중 종목 행 클릭에 stale ref가 섞여 의도치 않은 요소가 클릭되었고, 그 과정에서 브라우저가 프로덕션(jaroo.kr/screenshot)으로 이동했다(2회). 직후 확인 시점에는 6종목 모두 정상 존재했으나, 이후 세션이 만료·대체되어 최종 상태의 서버측 확인은 불가다. 본 스크립트는 재발 방지로 행 확장 클릭을 기본 비활성(BB_EXPAND_ROWS)하고 파괴 가능 라벨 클릭을 차단한다.
2. **딥스캔 이력 접근 불가**: 과제가 지목한 "딥스캔 이력"은 이전 계정에 있었으나 현재 계정(qa-auto)에서는 기록 페이지 자체가 로드 실패라 검증 불가(TC-015 FAIL). 보유 계정에서 재실행하면 TC-016~019가 자동 판정된다.
3. **로컬 진짜 구글 이탈**: 로컬 "Google로 시작하기" 클릭 시 accounts.google.com 계정 선택 화면에 실제 계정 정보가 노출되었다. 계정 선택은 하지 않고 즉시 복귈했다(TC-BBD-026 SKIP+보고).
4. **빈 상태 영역 외 로컬 미사용**: 과제 규칙에 따라 로컬은 빈 상태 확인(게스트)과 로그인 화면 비교에만 사용했다.

## 8. 재현 절차 요약

1. `BB_BASIC_AUTH=... node scripts/blackbox-data-sanity.cjs all` 실행 (요약·FAIL 목록 즉시 출력)
2. 보유 종목 계정에서는 `BB_EXPAND_ROWS=1` 추가 → TC-008/009 자동 판정
3. 딥스캔 이력 검증은 기록 페이지 로드 실패(TC-BBD-015) 해소 후 재실행
4. 색 규약·포맷·잔여값 검증은 현재 계정 상태에서도 즉시 재현 가능(TC-006/007/020/022/025)
