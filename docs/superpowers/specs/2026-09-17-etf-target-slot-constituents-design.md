# ETF 목표가 영역 대체(구성 종목 통합 카드) — 설계 (이슈 #270)

- **작성일**: 2026-09-17
- **상태**: 승인 대기 (사용자 설계 승인 완료 — 스펙 리뷰 대기)
- **추적**: GitHub #270 (라이브몰로 회의 2026-09-16 파생 · 기한 이번 주) · 선행 스펙 `2026-09-15-etf-real-data-design.md` (#265)
- **공수**: 카드 구현 0.5~1일 + 검토 문서 0.5일 (이번 주 마감 대응)

## 1. 배경

회의(2026-09-16)에서 "ETF에는 개별 종목식 목표가가 맞지 않으므로 목표가 칸에 구성 종목 등 대체 콘텐츠를 표시 — 기존 카드의 톤앤매너는 유지하고 내용만 교체"로 합의했다(#270). 함께 "차트(기술적) 분석 방향 검토"(펀더멘털 전면 분석은 비용 과다)와 "구성 종목 이벤트 상위 N 노출"이 검토 안건으로 남았다.

`/etf`에서 목표가를 대체해온 것은 **시나리오 카드(52주 범위 위치)**다. 이번 설계는 이 자리를 **구성 종목 카드로 교체**하고, 이미 별도로 존재하는 '구성 종목 Top 10' 카드와 병합해 중복을 없앤다. 2026-09-17 브레인스토밍에서 대상 화면(`/etf` 시나리오 카드 자리)과 콘텐츠 범위(구성 비중만)를 확정했다.

## 2. 승인된 결정 사항

| # | 결정 | 내용 |
|---|---|---|
| D1 | 대상 화면 | **`/etf` 시나리오 카드(52주 범위 위치) 자리**. `/deepscan` ETF 카드의 'ETF 기준' 플레이스홀더는 후속 과제로 기록만 |
| D2 | 교체 콘텐츠 | **구성 종목 비중만**. 구성별 당일 등락률·이벤트 Top-N은 후속 (사용자 선택 2026-09-17) |
| D3 | 카드 구조 | 시나리오 카드 + 기존 '구성 종목 Top 10' 카드를 **하나로 병합** — 요약 헤더(집중도 강조) + Top 10 리스트. `EtfResultCardShell` 문법·톤앤매너 유지 |
| D4 | 52주 위치 | 현재 위치 %는 **소실**(합의 안건 준수). 52주 저~고 범위는 리스크 카드에 이미 표시되어 정보 보존 |
| D5 | 차트 AI 분석 | 이번엔 **검토 문서만 산출**(§5). 구현은 검토 결과 확정 후 별도 이슈 |
| D6 | 미확정 안건 | 구성 종목 이벤트 Top-N — 검토 문서에 방안만 정리, 후속 이슈 분리 권고 |

## 3. 화면 설계 — 구성 종목 통합 카드

카드 배치 순서(변경 후): 헤더·인트로 → 시세 브리핑 → 상품 정보 → **구성 종목(신규, 기존 시나리오 자리)** → 기간별 수익률 → 리스크 지표 → 공유 카드. 기존 '구성 종목 Top 10' 카드 자리는 중복 제거로 사라진다.

```
┌ [ETF] 구성 종목                       [상위 10개] ┐   ← EtfResultCardShell (eyebrow '구성')
│            상위 10개 집중도                          │      badge `상위 ${n}개`
│               62.4%                                 │   ← 28px black 강조 (집중도)
│         ████████████░░░░░░░░                         │   ← 5px 게이지, width = 집중도%
│  1위 삼성전자 21.3% · 2위 SK하이닉스 15.2%            │   ← 상위 2개 요약 캡션(데이터 있을 때만)
│───────────────────────────────────────────────│
│ ● 삼성전자      005930              21.30%           │   ← 기존 Top10 리스트 문법 그대로
│ ● SK하이닉스    000660              15.20%           │      (파란 점 · 이름 · 코드 · 비중 바)
│ ● …                                                 │
│ note: 네이버 제공 기준 · 상위 종목 비중이 높은 편이에요  │   ← 출처 + 집중/분산 코멘트
└─────────────────────────────────────────────────┘
```

**계산·문구 규칙**

- 집중도 = `clamp(0, 100, Σ top10 weightPct)`, 표시는 소수 1자리
- 상위 요약 캡션: "1위 {이름} {비중}% · 2위 {이름} {비중}%" — 2개 미만이면 있는 만큼만, 0개면 미표시
- 집중/분산 코멘트: ≥60% "상위 종목 비중이 높은 편이에요" / ≤40% "고르게 분산돼 있어요" / 나머지 "중간 정도로 분산돼 있어요"
- KR 출처 문구 "네이버 제공 기준" / US "Yahoo Finance 제공 기준" (기존 holdings summary 문구 계승, "구성등락률은 소스 준비 중" 문구는 등락률 미표시로 불필요해져 제거)
- US는 제공 topHoldings 개수 n 그대로 표시(n < 10이면 캡션·badge `상위 n개`, 집중도 캡션도 n 기준)
- holdings 데이터 부재/빈 배열: 기존 관례(선행 스펙 D7)대로 `EtfNoticeSection`(source-pending, "구성종목은 소스 연결 후 보여줘요")를 같은 자리에 노출

**인트로 카피 수정** — 스테일 문구 교체(구성·리스크는 이미 실데이터):

> (전) 오늘 장 기준 시세와 상품 정보를 먼저 보여드려요. 구성·리스크는 소스 연결 후 이어집니다.
> (후) 오늘 장 기준 시세와 상품·구성·리스크를 한 흐름으로 정리해드려요.

## 4. 코드 변경 지점

데이터 계약(`jaroo-etf-profile-v1`)·크롤러·API·DB는 **변경 없음**. 웹 화면 계층만 수정한다.

| 파일 | 변경 |
|---|---|
| `src/lib/etf/etf-view-model.ts` | `EtfScenario`·`EtfScenarioBlock`·`buildScenarioBlock` 삭제. `EtfHoldingsBlock`에 `headline: { concentrationPct, concentrationText, topSummaryText }` 추가 — 계산은 순수 함수(예: `buildHoldingsHeadline`). holdings summary 문구 규칙 §3 반영 |
| `src/app/etf/page.tsx` | `EtfScenarioCard`·`EtfHoldingsCard` 제거 → 통합 카드 1개(가칭 `EtfHoldingsSummaryCard`)를 상품정보 다음에 배치. 시나리오 렌더 분기 제거. 인트로 카피 수정 |
| `tests/etf-view-model.test.ts` (신규) | 집중도 계산·100 초과 clamp·코멘트 3분기·holdings 부재 폴백·US n<10 케이스. 기존 `run-web-ts-tests` 대상 |

## 5. 차트 기반 AI 분석 방향 검토 문서 (별도 산출물)

이슈 #270 기대동작 2번("차트 기반 AI 분석 방향 검토 결과 정리")을 문서로 충족한다.

`docs/reports/etf-ai-analysis-direction-2026-09-17.md`:

1. **배경** — 펀더멘털 전면 분석 비용 과다(회의 L706-751), 구성별 컨센서스 크롤 13페이지×N건 비용(선행 스펙 §5)
2. **현행 구조** — `/etf` 무과금 vs 딥스캔 10크레딧, LLM(deepseek-v4-flash·OpenRouter), 차트 데이터(일봉·변동성·MDD·샤프·52주)는 이미 확보
3. **차트(기술적) 분석 방향 제안** — 추가 데이터 비용 ≈ 0, 기존 지표 요약을 LLM 프롬프트에 투입하는 구조, 과금 정책 옵션(무과금 유지 vs 크레딧 도입) 비교·권고
4. **구성 종목 이벤트 Top-N 방안**(미확정 안건) — 소스 후보(공시 캘린더·실적발표 일정)와 비용 검토, 후속 이슈 분리 권고
5. **결론** — 다음 스텝 제안

완성 후 이슈 #270에 요약 코멘트를 다는 것은 **내용을 사용자에게 보여드리고 승인 후** 게시한다.

## 6. 범위 외 (후속 과제 기록)

- `/deepscan` ETF 카드의 'ETF 기준 / NAV·구성 확인' 플레이스홀더 개선 (D1)
- 구성 종목별 당일 등락률 연동 — 크롤러 일괄 quotes(`etf-profile.js` "2단계" 주석, 뷰모델 `changePct` 필드는 이미 준비)
- 구성 종목 이벤트 Top-N 구현 (D6)
- 미사용 뷰모델 블록 정리(`momentum`·`sectorWeights`·`peers`·`dividendInfo` — 현재 렌더되지 않음)
