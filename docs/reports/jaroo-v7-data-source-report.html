v7 최소 ViewModel 계약 제안

기존 canonical payload를 직접 화면에 꽂지 말고, v7 화면 전용 projection을 두는 것이 안전하다.

type DeepScanV7ViewModel = {
  stock: { name: string; code?: string; market?: string; qty?: number }
  profit: { pct?: number; amount?: number; portfolioTotal?: number }
  quote: {
    current?: number; open?: number; high?: number; low?: number
    volume?: number; prevClose?: number; prevVolume?: number
    week52High?: number; week52Low?: number; avgPrice?: number
    kospiPct?: number; kosdaqPct?: number
    daily: Array<{ date: string; open?: number; high?: number; low?: number; close: number; volume?: number }>
    asOf?: string
  }
  llmEtaSec: number
  teams: Array<{
    id: 'market' | 'sentiment' | 'fundamental'
    name: string
    subtitle: string
    summary: string
    verdict: 'positive' | 'neutral' | 'negative'
    tags: Array<{ text: string; type: 'plus' | 'minus' | 'neutral' }>
    basis: Array<{ k: string; v: string }>
  }>
  conclusion: {
    label: '강세' | '우세' | '관찰' | '주의' | '위험'
    barCount: 0 | 1 | 2 | 3 | 4 | 5
    distributionText: string
    summary: string
    scenarios: Array<{ name: string; pct: number; trigger: string; recommended?: boolean }>
    facts: { targetPrice?: number; upsidePct?: number; opinion?: string; opinionScore?: number; firmCount?: number }
  }
}

구현 우선순위

P0 · 화면 시작
v7 컴포넌트와 ViewModel projection을 먼저 만든다. 없는 값은 데이터 없음으로 처리하고, 점수/위원회/디버그 문구를 숨긴다.
P1 · 즉시 시세
/api/quotes/current 결과 + Home/OCR target으로 현재가/평단/수량/손익/52주 위치를 채운다. 이 단계만으로 v7 시세 카드의 60~70% 구현 가능.
P2 · OHLCV 보강
KRX 종목 OHLCV와 KRX index OHLCV proxy를 추가해 일봉 차트, 한 달 흐름, 3일 연속 상승, 전일 거래량 배율, 코스피/코스닥 비교를 실제값으로 채운다.
P3 · DeepScan projection
기존 /api/deepscan payload에서 세 팀 요약, verdict, basis, 목표가/투자의견/증권사 수를 v7 계약으로 변환한다. 점수 숫자는 내부 계산에만 사용한다.
P4 · 품질 테스트
시나리오 합 100%, 1970 날짜 미노출, 점수 미노출, 금지 배지 미노출, 평단 반올림, 수급 미노출을 회귀 테스트로 고정한다.

주의점과 결정 필요 사항

1. 전체 포트폴리오 평가액
v7 인트로 톤은 종목 손익률이 아니라 손익액 / 전체 포트폴리오 평가액 기준이다. 현재 화면 handoff에 이 값이 없다면 Home aggregate에서 넘기거나, 임시 fallback 정책을 정해야 한다.

2. “시세 조회 1회 스냅샷” 원칙
v7은 tick streaming이 아니다. 분석 시작 시점에 quote snapshot을 고정하고, LLM 도착 전까지 같은 값을 기준으로 브리핑을 생성하는 것이 맞다.

3. 수급 데이터 금지
외국인/기관 수급, 호가 등 실시간 불가 데이터는 화면과 근거 펼침에서 제외한다. 기존 “수급 추적기” 표현도 v7에서는 “거래량” 중심으로 바꿔야 한다.

4. 날짜 fallback
1970-01-01은 절대 노출하지 않고 데이터 없음 또는 수집 완료로 변환한다.
