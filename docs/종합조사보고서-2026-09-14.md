## 2. 조사 방법과 검증 증거

### 2.1 수행한 조사

1. **gstack autoplan 파이프라인** (CEO → Design → Eng, 6원칙 자동결정) — 기존 문서 교차검증(8/31)·PM 보고서·railway 마이그레이션 문서 대조 + 실제 코드 독해
2. **정적 코드 감사** — 라우트 인증/비용 표면 전수 점검, 목업 데이터 사용처 매핑, 품질 메트릭(파일 크기·catch·alert·any)
3. **라이브 프로브** — 운영 도메인 응답 헤더 비교
4. **로컬 게이트 재현** — typecheck/lint/test 직접 실행
5. **저장소 상태 확인** — GitHub Actions 실행 이력, 마이그레이션 SQL, 워크플로우 파일

## 3. 현재 상태 종합

### 3.1 검증된 양호 (건드리지 말 것)

- **딥스캔 전 경로**: 크레딧 게이트→크롤러→LLM→브리핑 스냅샷(캐시+inflight dedup)→목표가 팬차트. 실패 시 자동 크레딧 환불(구 P0 해결됨)
- **결제 인프라**: 승인/취소/빌링키/웹훅(재조회 검증)/멱등 갱신 워커/past_due 7일 유예 — 스위치만 남음
- **워치**: 등록·강도 선택·해지 UI + 일일 배치 + 텔레그램 알림 실구현
- **코드 품질 기반**: `any` **0건**, API 인증 단일 헬퍼(`lib/supabase/api-auth`), 낙관 업데이트+롤백, status-union 에러카드, 비밀번호 재설정 견고
- **UI 규칙 수습 완료**: 초록 토큰 중립화, 홈 이모지 제거, 도넛 팔레트 무초록 (교차검증 8/31 이후)

### 3.2 깨져 있거나 비어 있는 것

- CI 게이트 레드 → Railway는 현재 **무검증 배포 중** (G1)
- 프로덕션 도메인 이원화 (G2)
- 과금 전면 OFF + 신규 유저 결제 벽 예약됨 (G3+E4)
- 구독 갱신이 안 돌아감 — 워커는 완성, 호출자 없음 (G4)
- 서버 에러 수집이 콘솔뿐 (G6)
- "기록" 탭·알림 섹션이 테스트 데이터 (A3·A4)
- 목업 페이지 2종이 프로덕션에서 서빙 중 (A1·A2)
- OCR 유료 호출 난립 → **해결(2026-09-14, 4겹 가드)** (B1)
