## 1. 한눈에 보는 화면 맵

```
[처음 사용자]
  스크린샷 추가(로고+소개)
        ↓
  인식 중 (자동 추출)
        ↓
  종목 확인 (정상 접힘 + 실패 후보 + 병합)
        ↓
  ┌─────────────  홈  ─────────────┐
  │  도넛(비중+전체손익) + 종목 카드   │
  └────────────────────────────────┘
        ↓ 종목 탭 → 펼침 → 딥스캔 버튼
  딥스캔 분석 (60초 실시간)
        ↓
  딥스캔 결과 (세 팀 + 결론 + 시나리오)
        ↓
  ┌──── 여기서 워치로 분기 ────┐
  │  "이 종목 지켜봐드릴까요?"   │
  │  (홈 종목카드 [지켜보기]      │
  │   / 마이 워치 카드로도 진입)  │
  └───────────────────────────┘
        ↓
  포트폴리오 워치 (구독)

[기존 사용자]
  홈 → [+] → 스크린샷 추가 → (같은 흐름) → 홈 병합

[로그인]  저장/구독 시점에 유도 (첫 진입 강제 X)
[마이]    프로필·크레딧·워치·종목관리·분석기록
```

## 2. 사용자 여정 — 단계별 목적

| 단계 | 화면 | 사용자 상태 | 이 화면의 일 |
|---|---|---|---|
| 진입 | 스크린샷 추가 | "뭘 올려야 하지" | 예시로 막막함 해소, 자동 추출 |
| 인식 | 인식 중 | 5초 대기 | 스캔 애니메이션 + 시간 안내 |
| 확인 | 종목 확인 | "맞나 확인해야" | 정상 접기, 실패만 후보로, 1회 적용 |
| 파악 | 홈 | "내 상태가 어떻지" | 총 평가액 + 손익 + 도넛 + 종목별 |
| 대기 | 딥스캔 진행 | 60초 불안 | 시세 브리핑으로 채움 |
| 판단 | 딥스캔 결과 | "팔까 버틸까" | 세 팀 + 결론 + 시나리오 |
| **지속** | **워치** | **"계속 불안한데"** | **지켜보고, 바뀌면 알림** |

핵심 전환점: **딥스캔(일회성) → 워치(지속)**. 여기가 BM의 축.

## 3. 워치 내부 흐름

```
[진입점]
  홈 종목카드 펼침 → [딥스캔 분석] [지켜보기]  ← 손실 종목은 지켜보기 강조
  마이페이지 → 포트폴리오 워치 카드
  딥스캔 결과 후 → "이 종목 지켜봐드릴까요?"
      ↓
[등록 유도]  "매번 확인하는 거 힘드시죠"
      ↓
[워치 대시보드]
  ├ 무료 체험 배너 (D-5)
  ├ "이번 주는 확인할 게 없어요"  ← 유형2 안심
  ├ 종목별: 본전거리 + 지난주 대비 변화 + 상태
  └ 종목별 다음 확인 시점 (D-6, 지금, D-24)
      ↓ 종목 탭
[종목 상세]
  ① "8월 5일까지 안 보셔도 괜찮아요"  ← 최상단 안심
  ② 진행감 — 본전까지 +16.7%, 3주 전보다 2.1% 가까워짐
  ③ 최악 시나리오 — 52주 최저 기준 −73,700원
  ④ 기다림의 조건 — 3개 중 2개 충족 (이벤트로 갱신)
  ⑤ 다가오는 이벤트 — D-6 실적발표 [분기점]
  ⑥ 지금 팔면 / 안 팔면 (선택의 대칭)
  ⑦ 더 살까 — 물타기 시뮬레이터
  ⑧ 나만 그런 게 아니에요 — 68% 손실 구간
      ↓
[지켜본 기록]  이벤트가 "내 종목 의미"로 번역돼 쌓임

[알림 설정]
  "안 보고 싶어요" (월 1~2회) / "적당히 알려줘요" (주 1~2회, 기본) / "다 알고 싶어요" (주 3~5회)
  + 어떤 설정이어도 알림: 거래정지·상장폐지·근거 완전 붕괴 (끌 수 없음)
  + 상황별 제안: "다음 주 실적이에요, 그 주만 늘릴까요?"
  + 종목별 설정은 두지 않음 → 손실 종목은 자동으로 더 챙김
```

## 5. 관통하는 설계 원칙

### 5-1. 색 (한국식)
```
#0F1419  먹색   → 모든 액션 (버튼·딥스캔·링크·토글)
#E5484D  빨강   → 수익·상승 (한국 증시 관습)
#2B6BE6  파랑   → 손실·하락
#F5F6F8  배경 / #fff 카드 / #E8EAEE 라인
(구글 로고만 공식 4색 예외)
```
손익 빨강·파랑이 **유일한 컬러**. 나머지는 무채색 → "손익을 보는 앱"이 색으로 명확.

### 5-2. 숫자·용어
- 점수 전면 폐기 (딥스캔 84, 포트폴리오 66, 시장 57) → 라벨 + 실제 금액
- 평단·금액 정수 반올림
- "9인 위원회" → "세 팀", "300cr" → 횟수("딥스캔 4회")
- 개발자 용어·디버그 텍스트 전부 제거

### 5-3. 클릭 최소화
- 자동 추출 (버튼 제거), 확인 화면 1개로 통합
- 정상 종목 접기, 실패만 후보 제시
- OCR 흐름 7~8클릭 → 3~4클릭

### 5-4. 태도 — "모르고 기다리는 것과 알고 기다리는 것은 다르다"
- 손절 강요 X, 버티기 조장 X → **판단에 필요한 진실만 정확히**
- 물타기도 막지 않고 수학만 보여줌 ("Jaroo는 권하지 않아요. 숫자만 정확히")
- 나빠지면 나빠졌다고 정직하게 ("3주 전보다 4.4% 멀어졌어요")

## 6. BM 요약

```
딥스캔 (건별)  →  일회성 진단, 크레딧 소모
포트폴리오 워치 (구독)  →  버티는 동안 지속 감시

과금 후보:  A. 포트폴리오 전체 월정액 / C. Pro 통합 (비교표는 BM 문서 §4-B)
무료 체험:  며칠간 전체 개방 → 유료 전환
```

### 사용자 두 유형
| | 유형 1 (계속 봄) | 유형 2 (안 봄) |
|---|---|---|
| 문제 | 정보 과잉, 불안 증폭 | 결정적 순간도 놓침 |
| 워치 역할 | 필터 — 중요한 것만 | 대리 감시 — 대신 봐줌 |
| 파는 것 | 피로 감소 | **안심 (보험 구조)** |

유형 2는 앱을 안 켜도 **구독은 유지** → 리텐션 무관 매출. "안 봐도 된다"를 파는 게 다른 앱이 못 하는 포지션.

### 유인 정렬 (반드시 지킬 것)
- 손절 신호는 정직하게. 팔면 "잘 파셨어요, 다음 종목" 으로 관계 지속
- 종목당 과금(안 B)은 **금지** — 손절이 구독 해지가 되면 버티기 조장 유인 발생

## 7. 이벤트 처리 3층

```
층 1 (알림 O)   내 종목 직접 — 실적·공시·수주·증자
층 2 (기록만)   배경 — 미국장·환율·업황  → "내 종목 영향: 제한적/긍정적"으로 번역
층 3 (차단)     무관 — 테마주·루머  → "147건 걸러냈어요"
```
알림 문구는 **항상 종목명으로 시작**. "나스닥 -3% 급락"(공포) X → "SFA반도체에 영향이 있을 수 있어요"(내 얘기) O.

## 8. 남은 일

### 화면
- [ ] 포트폴리오 전체 관점 (어느 종목부터 손댈지 우선순위)
- [ ] 세금·수수료 반영한 실수령 손익
- [ ] 내 판단 기록 (회고)

### 백엔드
- [ ] OCR 매칭 정규화 (# 등 특수기호 — MTS별 상이)
- [ ] 점수 모델 정리 (UI는 폐기, 백엔드 별개)
- [ ] 이벤트 연관도 판정 로직 (층 1/2/3 분류)
- [ ] 브리핑 속도 동적 조절 (`llm_eta_sec`)
- [ ] 첫 분석(40~60초) 백그라운드 + 알림

### 검증
- [ ] 실사용자 5명 — 60초 대기 체감, 도넛 직관성, "안 봐도 됨" 안심 효과
- [ ] 무료 체험 기간(N일) — 변화가 한 번은 감지될 길이
- [ ] 과금 모델 확정 (A vs C)
