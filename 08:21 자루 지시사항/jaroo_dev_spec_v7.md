# Jaroo 분석 결과 화면 — 개발 전달 명세 (v7 기준)

기준 프로토타입: `jaroo_final_v7.html`
한 줄 요약: 종목 탭 → 시세 즉시 브리핑(움직임) → 세 팀 분석 → 종합 결론. 한 페이지, 끊김 없이 이어짐.

---

## 0. 핵심 설계 원칙

1. **시세(즉시 가능) vs LLM(느림) 분리** — 시세 조회로 나오는 건 0초부터 보여주고, LLM 분석만 기다린다.
2. **기다림을 브리핑으로 채운다** — LLM 도는 동안 빈 화면 대신, 시세 데이터를 가공한 브리핑을 움직임과 함께 단계적으로 보여준다.
3. **점수 없음** — 강세 라벨 + 5단계 막대 + 팀 의견 분포로 대체 (정밀 점수 모순 제거).
4. **결론에 "답"** — 상태(강세)뿐 아니라 행동(보유 유지 시나리오)까지.

## 1. 데이터 도착 시점 (중요)

| 데이터 | 도착 | 비고 |
|---|---|---|
| 현재가, 손익률, 손익액 | 즉시 | 실시간 시세 조회 (분석 시작 시 1회) |
| 시/고/저, 거래량, 52주 고저 | 즉시 | 동일 조회 |
| 전일 종가/거래량 | 즉시 | 동일 조회 |
| 코스피/코스닥 지수 | 즉시 | 동일 조회 |
| 일봉 (3개월) | 즉시 | 차트용 |
| 평단/보유수량 | 즉시 | OCR 데이터 (사용자) |
| **목표가, 상승여력, 투자의견** | **지연** | 크롤링/LLM (≈40~60초, 캐시 시 10~20초) |
| **세 팀 분석 요약** | **지연** | LLM (병렬, 캐시 시 빠름) |
| **종합 결론(강세/시나리오)** | **지연** | LLM 종합 |

- 안 되는 것: 실시간 수급(외국인/기관), 호가 → 화면에서 제외
- 시세 조회는 **분석 시작 시 1회 스냅샷** (틱 스트리밍 아님)

## 2. 화면 세로 구조

```
[Sticky 헤더]   종목명 + 손익 (고정)
[인트로]        종목명 + 손익 상황 한 줄
[시세 카드]
  ├ 현재가 + 손익 + 평단
  ├ 일봉 차트 (평단선)
  └ 브리핑 6개 (단계 펼침)
[합친 박스]     "시세 봤고 → 분석 중" + 스피너 + 카운트다운
[세 팀]         각 팀 요약 + 근거 펼침
[결론]          강세 + 막대 + 분포 + 종합문장 + 시나리오 + 목표가
[디스클레이머]
```

## 3. 타이밍 (LLM 시간에 비례하여 동적)

데모 기준(LLM 60초 가정):

| 시점 | 동작 |
|---|---|
| 0~5초 | 일봉 차트가 왼→오 그려짐 |
| 6,11,16,22,28,33초 | 브리핑 6개 순차 등장 (각 항목 제목→데이터→의미 펼침) |
| ~38초 | 브리핑 끝 → 합친 박스 등장 (전환멘트+카운트다운) |
| 38~48초 | LLM 대기 (타이핑 인디케이터) |
| 48,50.5,53초 | 세 팀 순차 등장 (타이핑→텍스트) |
| ~56초 | 종합 결론 (막대 순차 점등 + 시나리오 바 채움) |

**캐시된 종목(LLM 10~20초) 대응:** 브리핑 간격을 LLM 예상 시간에 맞춰 압축.
```
브리핑 간격 = (LLM예상시간 − 차트시간) / 브리핑개수
LLM 15초 → 간격 2초, LLM 60초 → 간격 8초
```
같은 화면·항목, 속도만 다르게. LLM 끝나는 시점에 브리핑도 자연스럽게 끝나도록.

## 4. 인트로 (손익 5단계 동적)

종목명 + 손익 상황 한 줄. **금액 없이**, 상황만.

| 구간(전체자산 대비) | 인트로 |
|---|---|
| +20%↑ | "{종목}, 꽤 오르셨네요" |
| +3~20% | "{종목}, 수익 구간이에요" |
| −3~+3% | "{종목}, 거의 본전이네요" |
| −15~−3% | "{종목}, 조금 빠졌네요" |
| −15%↓ | "{종목}, 쉽지 않은 구간이네요" |

판정 기준 = **전체 자산 대비 충격** (`손익액 / 전체 포트폴리오 평가액`), 종목 손익률 아님.
(종목 −10% 여도 전체 비중 작으면 가벼운 톤)

## 5. 시세 카드

### 5-1. 헤더
현재가, 손익률/액(색: 수익 초록 #1A9D55 / 본전 회색 #5A6473 / 손실 빨강 #E5484D), 평단·보유수량.

### 5-2. 일봉 차트
- 최근 3개월 일봉, 왼→오 그려지는 애니메이션 (≈5초, LLM 시간 따라 조정)
- **내 평단 점선(가로)** + 라벨
- 현재가가 평단 위=초록 선, 아래=빨강 선 + 영역 음영
- 끝점(현재가) 깜빡이는 링

### 5-3. 브리핑 6개 (단계 펼침)
각 항목 = **질문 → 데이터 → 의미** 3단계로 펼쳐짐 (제목 0s, 데이터 +1.2s, 의미 +2.4s). 숫자는 카운트업.

순서 (큰 그림 → 현재, 희망 먼저):

| # | 질문 | 데이터 | 의미 | 출처 |
|---|---|---|---|---|
| 1 | 최근 한 달 흐름? | +12.3% | 바닥 다지고 회복 중 | 일봉 |
| 2 | 단기 흐름은? | 3일 연속 상승 | 흐름 살아남 | 일봉 |
| 3 | 내 자리는? | 본전까지 +0.4% | 고점서 샀지만 55원이면 회복 | 현재가+평단 |
| 4 | 오늘 시장 속? | 코스피+0.8/코스닥−0.3/내종목+0.2 | 시장 좋은데 덜 따라옴 | 지수+현재가 |
| 5 | 오늘 하루? | 반등 흐름 | 저가서 올라 고가 부근 | 시/고/저 |
| 6 | 거래는? | 어제의 1.4배 | 관심 붙은 하루 | 거래량+전일 |

카피 원칙: 희망적 먼저, 아픈 사실(고점 대비 손실)은 긍정 프레임("55원이면 회복"). 질문형은 과하지 않게.

## 6. 합친 박스 (전환 + 대기)

브리핑 끝 → 세 팀 등장 전, **하나의 박스**:
```
시세는 다 봤어요. 이제 세 팀이 더 깊이 분석하는 중이에요.
─────
⟳ [진행 상태 텍스트]              0:10
```
- 전환 멘트(위) + 스피너·카운트다운(아래) 한 박스
- 카운트다운 = 세 팀 도착까지 남은 시간
- 세 팀 도착 시 박스 통째로 사라짐(슬라이드 업)

---

## 7. 세 팀 (LLM 요약 + 근거 펼침)

각 팀: 아바타 + 이름 + 부제(소속 3명) + LLM 요약 + 태그 2개 + **근거 펼침**.

| 팀 | 부제 | 담당 |
|---|---|---|
| 시장·차트 팀 | 차트 마스터·거래량·상승세 추적 | 가격위치·추세·거래량 |
| 심리·환경 팀 | 증권사 의견·산업 전문가·이슈 탐색 | 목표가·산업·이벤트 |
| 가치·기본 팀 | 가치 분석·성장 전략·재무 점검 | 수익성·밸류·지배구조 |

**등장:** 타이핑 인디케이터(● ● ●) → LLM 도착 시 텍스트로 교체, 순차(2~3초 간격).

**근거 펼침 (기본 접힘):** LLM 요약은 그대로, 펼치면 그 팀 요약의 **출처 정형 수치** (LLM 미경유).

| 팀 | 근거 데이터 (시세로 가능한 것만) |
|---|---|
| 시장·차트 | 현재가 / 20일 이동평균 / 52주 위치 / 거래량(전일 대비) |
| 심리·환경 | 평균 목표가 / 투자의견 / 분석 리포트 수 / 최근 변동 |
| 가치·기본 | 영업이익 / PER·PBR / ROE / 지배구조 |

※ 수급(외국인/기관)은 실시간 불가 → 근거에서 제외.

**카피 원칙:**
- 세 팀이 같은 말 반복 금지. "상승 여력"은 결론에만, 팀 요약엔 X.
- 어조 통일: 정중한 친근체 "~이에요/예요".
- 단정·보장 표현 금지 ("추가 리스크 없음" → "추세 이탈 시 검토").
- 팀 간 의견 중복 금지 (밸류 우려는 가치·기본 팀에만).

## 8. 종합 결론 (상태 + 답 + 근거)

순서대로:

### 8-1. 상태
- "강세" 라벨 (크게) — 5단계: 강세/우세/관찰/주의/위험
- 5단계 막대 ●●●●○ (순차 점등 애니메이션)
- "3팀 중 2팀 긍정 · 1팀 중립" 의견 분포

**막대/라벨 = 팀 verdict 집계로 계산** (정밀 점수 불필요):
| 긍정 팀 | 막대 | 라벨 |
|---|---|---|
| 3 | ●●●●● | 강세 |
| 2(+중립1) | ●●●●○ | 강세 |
| 2(+부정1)/1+중립2 | ●●●○○ | 우세 |
| 전부 중립 | ●●○○○ | 관찰 |
| 부정 우세 | ●●○○○~●○○○○ | 주의 |
| 3 부정 | ○○○○○ | 위험 |

### 8-2. 종합 문장 (한 줄)
손익 상황 + 판단. 예: "거의 본전이고 상승 여력이 남아 있어, 지금 서둘러 정리하기보다 1–2주 더 지켜보는 게 좋겠어요."
(손익 5단계 톤 반영)

### 8-3. 추천 행동 (시나리오, 합 100%)
| 행동 | 비율 | 트리거 |
|---|---|---|
| 보유 유지 [추천] | 62% | 목표가 도달 시 분할 매도 |
| 추가 매수 | 23% | −10% 도달 시 평단 낮추기 |
| 손절 | 15% | 지금 팔면 −877원 · 추세 이탈 시 검토 |

- 합 정확히 100% (정규화 필수)
- 손절에 즉시 매도 시뮬(지금 팔면 얼마) 통합
- 바 채워지는 애니메이션

### 8-4. 근거 숫자 (그리드)
평균 목표가 / 상승여력 / 투자의견 / 증권사 수. (지연 데이터, 결론과 함께 도착)

## 9. 삭제·금지 (사용자 노출 X)

- 점수 숫자 (DeepScan 84 등) — 라벨로 대체
- 디버그: "덤프 기반…", "LLM 위원 3/3", "포트폴리오 점수 76→78"
- 정체불명 배지: "원천 상태 표시", "위원회 4개 응답", "현재가 확인", "한줄 요약 완료", "팀 요약 완료"
- 중복: 현재가는 시세카드/근거펼침에만, 평가손익은 한 곳만
- 1970-01-01 날짜 fallback (데이터 없으면 "데이터 없음")
- 평단 소수점 → 반올림 (14,239.84 → 14,240)

## 10. 데이터 계약 (백엔드 → 프론트)

```jsonc
{
  "stock": { "name", "code", "market", "qty" },
  "profit": { "pct", "amount", "portfolio_total" },   // 손익 멘트용. 즉시.
  "quote": {                                          // 시세, 즉시
    "current", "open", "high", "low", "volume", "prev_close", "prev_volume",
    "week52_high", "week52_low", "avg_price",
    "daily": [ {date, close} ],                       // 일봉 3개월
    "kospi_pct", "kosdaq_pct"
  },
  "llm_eta_sec": 15,                                   // LLM 예상 시간 → 브리핑 속도 계산
  "teams": [                                           // 지연 (LLM)
    { "id", "summary", "verdict":"positive|neutral|negative",
      "tags":[{text,type}], "basis":[{k,v}] }          // basis는 정형 수치(LLM 미경유)
  ],
  "conclusion": {                                      // 지연
    "label":"강세", "positive_count":2, "neutral_count":1, "negative_count":0,
    "summary":"한 줄 종합",
    "scenarios":[ {name, pct, trigger} ],              // 합 100
    "facts": { target_price, upside_pct, opinion, opinion_score, firm_count }
  }
}
```

### 역할 분담
- **즉시 표시:** quote, profit → 시세 카드 + 차트 + 브리핑 + 인트로 멘트 (프론트 계산)
- **브리핑 멘트:** quote/profit으로 **프론트가 생성** (백엔드 문구 X)
- **teams[].summary:** LLM 생성 (§7 카피 원칙 적용)
- **teams[].basis:** 정형 수치 (LLM 미경유)
- **conclusion.label/막대:** teams verdict 집계 (정밀 점수 불필요)
- **llm_eta_sec:** 브리핑 속도 동적 조절용 (캐시면 작게)
