# Jaroo 디자인 시안

상사 제공 **기획서 겸 디자인 시안**(HTML 목업). 구현 시 실제 컴포넌트/CSS로 반영한다.

## 목록

| 경로 | 화면 | 비고 |
|---|---|---|
| `login/jaroo_login.html` | 로그인 | "Jaroo — 로그인" |
| `mypage/jaroo_mypage.html` | 마이페이지 | "Jaroo — 마이페이지" |
| `mypage/jaroo_mypage_detail.html` | 마이 세부 | "Jaroo — 마이 세부" |

## 참고
- 각 파일은 단일 HTML(인라인 스타일)로, 브라우저에서 직접 열어보면 된다.
- 시안 그대로 구현하기보다는 Jaroo 기존 디자인 토큰(`var(--jaroo-*)`)·컴포넌트(`JarooShell` 등)에 맞춰 반영.
- 원본 출처: `~/Downloads/jaroo_*.html`(2026-07 상사 전달).
