개념

상단 가로 스와이프 캐러셀(snap 스크롤)로 캐릭터 4명(소심이🐰·몰빵준🚀·배당곰🐻·가치누나🦉)을 나열하고, 선택 시 아래 전체가 fade/slide 애니메이션으로 교체됩니다. 한 캐릭터를 집중 탐구하는 구조로 애착을 만듭니다.

구성

  • 페르소나 카드 — 큰 아바타, 성향 태그, 말풍선 말투 샘플, 여행자금 230만원까지 68% 진행 바
  • 계좌 요약 2×2 그리드(현금·매입원본·평가금액·총자산)
  • 판단 카드 — 결정 배지 + heroScore·회복확률·목표가, debugId, 캐릭터 서사, evidenceFacts 근거
  • 원장 Tabs — 체결 내역 / 보유 종목 (orderId·수수료·평단·평가손익)

데이터

mock-data.ts — 실제 컨트랙트 타입을 온전히 채운 리포트 5종(삼성전자·SK하이닉스·LG엔솔·기아·NAVER)

개념

프라이머리 그라디언트 시즌 헤더(2026년 11월 · 2주차) 아래 이번 주/지난 주/시즌 누적 탭으로 순위가 바뀌는 리그 페이지. 지난 주 4위 돌진이🚀가 이번 주 1위로 뒤집히는 스토리가 보입니다.

구성

  • 1위 강조 카드(크라운·큰 수익률) + 2~4위 컴팩트 행, 순위변동 ▲▼
  • 항목 탭 → 아코디언 펼침: 판단 로그(서사·debugId) → 계좌 요약 → 개인 최근 체결
  • 목표 진척도 — 소심이🐹 여행자금 230만원 93% 등
  • 하이라이트 매매 — "돌진이 SK하이닉스 +9.2% 익절"(리포트 인용 근거)
  • 4명 통합 최근 체결 피드

검증

390px 뷰포트 실측 — 가로 오버플로우 0, 아코디언·탭 전환·챔피언 교체 정상 동작 확인

증거 체인 타임라인형

판단 로그 × 매매 원장 = 공개 입증 체인
새 탭에서 열기 ↗

개념

"모든 매매는 deepscan 리포트에서 나온다"는 신뢰 입증이 페이지의 주인공. 시간 역순 통합 피드의 각 사가 카드 안에서 리포트 발행(파랑) → 판단(캐릭터색) → 체결(녹색/빨강) 노드가 커넥터로 한눈에 연결되고, 모든 체결의 orderId가 어떤 리포트 debugId에서 나왔는지 추적됩니다.

구성

  • 캐릭터 필터 칩 + 기간 탭(전체/오늘/지난 기록)
  • 노드 탭 → 펼침: 근거 fact 전체·위원회 축 점수·3m~3y 회수확률 바 / 원장 디테일(수량·단가·수수료)
  • 체결 없는 판단은 "홀딩 유지" 칩, 손익 배지(평가/실현 구분)
  • 하단 전체 사가 통계 — 리포트 4 → 판단 13 → 체결 6, 명중률 66.7%, 근거 추적률 100%

특징

5개 초안 중 deepscan 성능 입증에 가장 직접적인 구조

노드를 탭하면 근거·원장 디테일이 펼침
④

같은 리포트·다른 결정 비교형

AI 리포트는 하나, 해석은 성격타고 난다
새 탭에서 열기 ↗

개념

하나의 deepscan 리포트를 정점에 세우고, 동일 시드 300만원 계좌 4개가 그 리포트만으로 매매한 결과를 나란히 비교. 종목 탭(삼성전자 62점 | SK하이닉스 78점 | LG엔솔 41점)을 바꾸면 리포트 요약 → 4인 결정 → 계좌 비교표가 통째로 교체됩니다.

구성

  • 리포트 요약 — SVG 도넛 hero 게이지, 주간 시그널·목표가, 3m/6m/1y 회수확률 미니 바, "사용자와 동일한 리포트" 배지 + debugId
  • 4인 결정 카드 — 결정 배지(매수·매도·홀딩·관망 4색), 같은 근거 칩(62점·6m 52%) 위에 상반된 해석: 소심이🐰 "반 티켓만…" vs 돌진이🚀 "올인 직전" vs 배당콕☕ vs 가치누나📊
  • 체결 원장(side·수량·단가·수수료·orderId) + 현재 손익(확정/평가 구분)
  • 계좌 비교표 — 4인 현금 비중 바·수익률

특징

컴포넌트 분리(report-summary.tsx·decision-card.tsx)로 구조화 가장 잘 됨

종목 탭 전환 시 4인의 결정 세트가 교체
⑤

캐릭터 투자 일기·셰어러블형

감성 1인칭 일기 × 딱딱한 체결 영수증의 대비
새 탭에서 열기 ↗

개념

카톡 공유로 도는 "캐릭터 투자 일기" 콘텐츠. 날짜 헤더("11월 9일 (월) 😰") 아래 1인칭 일기 카드가 흐르고, 그 안에 "진짜 영수증" 표(체결 + orderId·수수료 + 계좌 요약)가 붙습니다. 미체결일은 기울어진 PASS 스탬프.

구성

  • 캐릭터 선택 가로 스크롤(소심이·돌진이·배당씨·가치누나) — 일기 전체 교체
  • 일기마다 "그날 본 deepscan 리포트" 근거 칩(종합 점수·6m 복구확률·목표가·reasonCode·debugId)
  • 주간 성적표 — OG 카드 스타일 큰 숫자 + 여행자금 진척 + 명대사
  • 하단 고정 CTA "내 포트폴리오도 무료 deepscan 받기" → /deepscan

특징

4인 전원이 동일한 리포트 3장(62·78·41점)을 보고 다르게 행동 — 데이터 레벨에서도 "같은 데이터, 다른 결정"
